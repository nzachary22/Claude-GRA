Grant Reporting Assistant for the ChatGPT app
=============================================

You need the ChatGPT desktop app (Windows or Mac) and Python 3.11 or newer.
The full guide with pictures of each step: https://github.com/nzachary22/Claude-GRA/blob/main/connector/CHATGPT.md

Install (once)
- Quit the ChatGPT app.
- Windows: double-click "Install on Windows.bat".
  If Windows says "Windows protected your PC", click "More info", then "Run anyway".
- Mac: right-click "Install on Mac.command" and choose "Open", then click "Open" again.
  If the Mac still refuses, open System Settings > Privacy & Security, scroll down and click "Open Anyway".
- It makes a private folder, your user folder > GRA Private Data. ChatGPT itself is blocked from opening it;
  only GRA reads it. When it asks about other private folders, usually click No.
- When it says it is installed, open the ChatGPT app again.

Try it
- Start a new chat in the ChatGPT app and type: Run the Grant Reporting Assistant sample report.
- The finished tables appear in the chat. The Word and Excel files, and an AI activity report,
  are saved in Documents > Grant Reporting Assistant.

Your own report
- Put your past report and data files in your user folder > GRA Private Data, then type something like:
  Use Grant Reporting Assistant to rebuild my 2025 report for January 1 to December 31, 2026.
  The files are in GRA Private Data.
- Never attach data files to the chat.
- Keep ChatGPT's permissions on the default, not Full access, in chats about client data.

To add a folder later, run the installer again. To remove GRA, open the Uninstall folder and run
the file for your computer.
